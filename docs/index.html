Nuvio RS Plus

Nuvio RS Plus is a personal Android TV media application based on Nuvio Reshaped, with additional Plus features.

Google Drive sync

Nuvio RS Plus can optionally connect to a user's Google account to synchronize application data through Google Drive.

The app requests the drive.file scope, which allows it to work with files it creates or that the user explicitly opens with the app. It does not request full access to all files in the user's Google Drive.

Privacy
